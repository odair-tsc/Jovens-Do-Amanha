# Jovens do Amanhã

Site desenvolvido para apresentar o programa **Jovens do Amanhã**, uma iniciativa de formação profissional do SENAI Mato Grosso do Sul (SENAI-MS).

O projeto tem como objetivo apresentar o programa, destacar suas informações e benefícios e facilitar o acesso dos visitantes às orientações sobre como participar.

## Sobre o projeto

O site foi desenvolvido com foco em uma navegação simples, visual moderno e adaptação para diferentes dispositivos.

A proposta é oferecer aos visitantes uma experiência intuitiva, permitindo conhecer o programa e consultar as etapas necessárias para participar.

## Funcionalidades

- Página inicial com apresentação do programa.
- Seções com informações sobre o programa e seus benefícios.
- Menu de navegação responsivo.
- Página interativa com um guia passo a passo sobre como participar.
- Indicador de progresso para acompanhar as etapas do guia.
- Links para consulta aos editais oficiais do SENAI-MS.
- Layout adaptado para computadores e dispositivos móveis.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript:** interatividade e navegação entre as etapas do guia.

## Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Navegue pelas seções da página inicial e acesse a opção **Como participar** para visualizar o guia interativo.

Também é possível utilizar a extensão **Live Server** do Visual Studio Code para executar o projeto durante o desenvolvimento.

## Objetivo
